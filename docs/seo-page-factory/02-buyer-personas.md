# Buyer Personas IndoRoster

> Pahami dulu siapa pembelinya, baru buat halamannya.
> Setiap persona punya search behavior, kebutuhan, dan pertanyaan yang berbeda.

---

## Persona 1 — Kontraktor Proyek

**Nama representatif**: Pak Andi, Kontraktor Bangunan

### Profil
- Mengerjakan proyek perumahan/ruko/gedung kecil-menengah
- Biasanya mengerjakan 1-5 proyek paralel
- Volume kebutuhan per proyek: 500–5.000 pcs
- Keputusan pembelian: sendiri atau bersama owner proyek
- Waktu riset: cepat, sibuk, butuh jawaban praktis

### Search Queries Khas
```
supplier roster beton proyek
harga roster beton proyek
pabrik roster beton
roster beton untuk kontraktor
grosir roster beton
roster beton siku presisi
supplier roster beton grosir
```

### Pertanyaan yang Perlu Dijawab Halaman
1. Apakah bisa memenuhi kebutuhan volume saya?
2. Konsistensi dimensi untuk kecepatan pasang tukang?
3. Bagaimana sistem pengiriman ke lokasi proyek?
4. Dokumen apa yang disediakan (surat jalan, invoice)?
5. Berapa minimum pemesanan?
6. Bagaimana cara memesan untuk proyek?

### Pain Points
- Dimensi tidak presisi → tukang lambat, boros semen
- Supplier tidak bisa pengiriman terjadwal → material numpuk/kurang
- Dokumen administrasi tidak lengkap → masalah pelaporan
- Tidak ada kepastian ketersediaan stok

### CTA yang Tepat
> "Kirim jumlah kebutuhan, lokasi proyek, dan jadwal pengiriman → tim siap membantu koordinasi."

### Halaman yang Relevan
- `/supplier-roster-untuk-kontraktor`
- `/supplier-roster-beton-proyek`
- `/grosir-roster-beton`
- `/supplier-roster-kontraktor-proyek-perumahan`
- Location pages: `/supplier-roster-beton-bekasi`, `/supplier-roster-beton-jakarta`

## Persona 2 — Developer Perumahan

**Nama representatif**: Pak Budi, Project Manager Developer

### Profil
- Mengerjakan perumahan 20–200 unit
- Butuh konsistensi motif dan dimensi antar unit
- Volume: 5.000–50.000 pcs per proyek
- Keputusan pembelian: melibatkan tim arsitek, purchasing, dan project manager
- Proses: formal, butuh dokumen vendor, quotation resmi

### Search Queries Khas
```
supplier roster proyek perumahan
roster beton untuk developer
roster beton cluster perumahan
supplier roster untuk developer
pengadaan roster beton proyek
vendor roster beton
roster beton untuk perumahan
```

### Pertanyaan yang Perlu Dijawab Halaman
1. Bisa konsisten motif dan dimensi untuk banyak unit?
2. Kapasitas produksi cukup untuk jadwal kami?
3. Bisa pengiriman bertahap sesuai fase konstruksi?
4. Dokumen vendor tersedia (NIB, NPWP, dll)?
5. Ada mekanisme penawaran resmi/quotation?
6. Produk apa yang cocok untuk fasad perumahan?

### Pain Points
- Ketidakkonsistenan motif antar unit → tampilan cluster tidak seragam
- Supplier tidak bisa memenuhi volume besar dalam waktu tertentu
- Proses pengadaan formal terhambat karena dokumen tidak lengkap

### CTA yang Tepat
> "Kirim detail proyek (jumlah unit, motif, jadwal) → tim sales proyek akan menghubungi Anda."

### Halaman yang Relevan
- `/supplier-roster-untuk-developer`
- `/roster-beton-proyek-perumahan`
- `/roster-beton-untuk-cluster-perumahan`
- `/pengadaan-roster-beton`
- `/supplier-roster-developer-cluster`
- Location: `/supplier-roster-developer-bekasi`, `/roster-beton-proyek-perumahan-bogor`

## Persona 3 — Pemborong / Mandor

**Nama representatif**: Pak Heri, Pemborong Bangunan

### Profil
- Mengerjakan rumah tinggal, renovasi, proyek kecil
- Volume: 200–2.000 pcs
- Keputusan pembelian: mandiri, cepat
- Sensitif terhadap harga dan kemudahan pemesanan
- Tidak butuh proses formal, butuh barang sampai tepat waktu

### Search Queries Khas
```
jual roster beton
beli roster beton
harga roster beton
roster beton murah
supplier roster beton
toko roster beton
roster beton untuk renovasi
roster beton fasad
```

### Pertanyaan yang Perlu Dijawab Halaman
1. Berapa harganya? (minimal range)
2. Minimum pemesanan berapa?
3. Bisa dikirim ke lokasi saya?
4. Ada motif yang cocok untuk rumah minimalis?
5. Cara pesan bagaimana?

### Pain Points
- Tidak tahu harga di depan → takut ketipu
- MOQ terlalu tinggi untuk proyek kecil
- Pengiriman tidak jelas

### CTA yang Tepat
> "WhatsApp langsung → kirim jumlah dan lokasi untuk info harga dan ketersediaan."

### Halaman yang Relevan
- `/supplier-roster-untuk-pemborong`
- `/harga-roster-beton`
- `/roster-beton-minimalis`
- `/roster-beton-untuk-fasad`
- `/roster-beton-untuk-ventilasi`

## Persona 4 — Arsitek / Desainer Interior

**Nama representatif**: Bu Sinta, Arsitek

### Profil
- Mendesain rumah/gedung klien
- Mencari produk yang secara estetika sesuai konsep desain
- Volume rekomendasi: bervariasi tergantung klien
- Keputusan pembelian: merekomendasikan ke owner/kontraktor
- Butuh: spesifikasi teknis, foto produk detail, pilihan motif

### Search Queries Khas
```
roster beton untuk fasad
roster beton minimalis
roster beton motif
roster beton dekoratif
roster beton untuk desain
roster beton modern
spesifikasi roster beton
roster beton ukuran
roster beton arsitektur
```

### Pertanyaan yang Perlu Dijawab Halaman
1. Motif apa saja yang tersedia?
2. Ukuran dan ketebalan tersedia apa?
3. Cocok untuk aplikasi fasad gedung?
4. Ada contoh aplikasi di proyek nyata?
5. Bisa request sampel?
6. Spesifikasi teknis (kuat tekan, material, finishing)?

### Pain Points
- Foto produk tidak cukup detail untuk presentasi ke klien
- Tidak ada spesifikasi teknis yang bisa dimasukkan ke RAB/dokumen desain
- Susah menemukan motif yang sesuai konsep desain spesifik

### CTA yang Tepat
> "Request katalog motif lengkap dan spesifikasi teknis via WhatsApp."

### Halaman yang Relevan
- `/roster-beton-untuk-arsitek`
- `/roster-beton-untuk-fasad`
- `/roster-beton-minimalis`
- `/roster-beton-dekoratif`
- `/spesifikasi-teknis-roster-beton`
- `/roster-beton-untuk-desain-minimalis`

## Persona 5 — Procurement / Bagian Pengadaan

**Nama representatif**: Bu Reni, Procurement Manager

### Profil
- Bekerja di perusahaan konstruksi/developer besar
- Proses pembelian formal: vendor registration, quotation, PO, invoice
- Volume: besar, reguler
- Keputusan: kolektif (disetujui manager/direktur)
- Butuh: legalitas vendor, dokumen resmi, harga transparan

### Search Queries Khas
```
vendor roster beton proyek
pengadaan roster beton
vendor material bangunan roster
supplier material konstruksi
quotation roster beton
penawaran harga roster beton proyek
vendor roster untuk tender
roster beton dokumen pengadaan
```

### Pertanyaan yang Perlu Dijawab Halaman
1. Dokumen legal apa yang tersedia (NIB, NPWP, SIUP)?
2. Bagaimana proses request quotation resmi?
3. Bisa support dokumen pengadaan (SPH, PO, faktur pajak)?
4. Kapasitas dan track record supplier?
5. Proses pembayaran dan termin?
6. Garansi produk?

### Pain Points
- Vendor tidak bisa kelengkapan dokumen formal
- Proses quotation tidak terstruktur
- Tidak ada single point of contact untuk proyek besar

### CTA yang Tepat
> "Kirim RFQ via WhatsApp atau email → tim sales B2B akan merespon dalam 1x24 jam."

### Halaman yang Relevan
- `/vendor-roster-beton-procurement`
- `/pengadaan-roster-beton`
- `/quotation-roster-beton`
- `/dokumen-pengadaan-roster-beton`
- `/profil-vendor-roster-beton`
- `/roster-beton-untuk-tender-proyek`

## Implikasi untuk Konten Halaman

Satu keyword bisa muncul dari 3 persona berbeda:

**"roster beton untuk proyek"**

- Kontraktor → butuh: volume, pengiriman terjadwal, harga proyek
- Developer → butuh: konsistensi motif, kapasitas, dokumen vendor
- Pemborong → butuh: minimal order kecil, harga, cara pesan

Jika target semua persona → buat **pillar page** dengan semua angle.
Jika target satu persona spesifik → buat **buyer-specific page**.

Inilah mengapa 103 halaman bisa dibenarkan — bukan variasi kata, tapi variasi kebutuhan.
