# SEO Kawasan Cheatsheet (Project Intent)

Target pembaca: pencari berdasarkan nama proyek/kawasan atau jenis bangunan spesifik — bukan kota besar umum, dan bukan profesi pembeli.

## 1. Dua Sub-Kategori Project Intent
*   **Kawasan/klaster spesifik**: `roster untuk perumahan [nama klaster]`, `supplier roster kawasan industri [wilayah]`, `roster ruko/komersial [nama kawasan]`.
*   **Jenis bangunan/proyek**: `roster beton untuk perumahan`, `roster beton untuk hotel`, `roster beton untuk cafe`, `roster beton untuk restoran`, `roster beton untuk fasad`, `roster beton untuk pagar`, `roster beton untuk teras`.

Jenis proyek yang perlu punya representasi konten (minimal artikel/section, idealnya halaman dedicated jika volume pencarian mendukung): perumahan, cluster, hotel, villa, cafe, restoran, apartemen, mall, kantor, masjid, sekolah, rumah sakit, commercial building.

## 2. Content Cluster: Project
Bangun cluster artikel per use-case, contoh:
*   "Roster Beton untuk Fasad Rumah Modern"
*   "Roster Beton untuk Pagar Minimalis"
*   "Roster Beton untuk Cafe & Resto — Estetik Industrial"
*   "Roster Beton untuk Hotel & Villa"

Setiap artikel harus punya value nyata: rekomendasi motif per use-case, estimasi kebutuhan, dan link ke produk terkait — bukan artikel tipis/generik.

## 3. Konten Studi Kasus per Kawasan (HARUS DATA NYATA)
*   Ubah galeri proyek nyata jadi konten SEO: "Pemasangan Roster di [Nama Kawasan/Klaster], [Kota]" — cerita singkat, jumlah keping terpasang, motif yang dipakai.
*   **Aturan keras dari Master Plan**: dilarang membuat proyek, partnership, atau kawasan fiktif demi SEO. Hanya publikasikan kawasan yang benar-benar pernah dikerjakan/dikonfirmasi datanya.
*   Saat menjalin kerja sama dengan developer baru, minta izin publikasikan nama proyek — ini menangkap pencarian orang yang riset kawasan tersebut, terutama di periode pra-launching/serah terima unit.

## 4. Struktur Silo
Kota besar (`seo-lokasi`) → Kawasan/proyek spesifik di kota tersebut (skill ini) → Halaman produk yang dipakai di kawasan tersebut (`seo-produk`). Internal linking mengikuti hierarki ini, jangan saling link berlebihan di luar topical relevance.

## 5. Schema untuk Area Proyek
Tambahkan `areaServed` pada schema `Organization`/`Product` untuk kawasan yang sudah pernah digarap — bukan `LocalBusiness` palsu seolah ada cabang di kawasan tersebut (aturan sama seperti di `seo-lokasi`).
