# Image SEO Cheatsheet

## 1. Penulisan Alt Text
*   Alt text wajib mendeskripsikan gambar dengan jelas dan mengandung variasi kata kunci target.
    *   *Buruk*: `alt="gambar1"` atau `alt="roster"`
    *   *Baik*: `alt="Foto pemasangan roster beton MMC abu-abu untuk pagar rumah minimalis di Tangerang"`
*   **Jangan campur terlalu banyak kata kunci sekaligus** (motif + kota + kawasan + jenis proyek dalam satu alt text) — pilih 1-2 elemen paling relevan dengan konteks foto tersebut, sisanya biarkan konteks halaman yang bicara. Ini menghindari kesan keyword stuffing di mata Google.

## 2. Penamaan File & Format
*   Gunakan nama file yang deskriptif dan dipisahkan tanda hubung (hyphen).
    *   *Buruk*: `IMG_12948.jpg`
    *   *Baik*: `roster-mmc-pagar-beton.webp`

## 3. Kompresi & Lazy Loading
*   Format WebP, target ukuran di bawah 200–300KB per gambar.
*   Gunakan lazy loading untuk gambar di bawah viewport pertama agar tidak menghambat Core Web Vitals (LCP).
