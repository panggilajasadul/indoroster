# Product Page SEO Cheatsheet

## 1. Struktur Judul Produk (H1)
*   Format ideal: `Roster [Nama Motif] [Ukuran] [Warna/Bahan]` (Contoh: *Roster Arorow 20x20x10 Terakota*).
*   Judul wajib berada dalam tag `<h1>` tunggal di setiap halaman detail produk.

## 2. Optimasi Konten Detail
*   **Focus Keyword Density**: Tempatkan kata kunci utama pada 100 kata pertama deskripsi, dengan kerapatan sekitar 1-2% sepanjang konten. Jangan berlebihan (keyword stuffing).
*   **Call-to-Action (CTA) Ganda**: sediakan dua CTA — "Belanja Sekarang" untuk pembelian eceran langsung, dan "Request Quotation"/"Pesan Jumlah Besar?" untuk kebutuhan proyek/volume besar. Jangan hanya satu CTA untuk semua skenario pembelian.

## 3. Data Wajib per Halaman Produk
Nama produk, SKU, motif, material, dimensi, berat, harga, MOQ (jika berlaku), status stok, gallery, spesifikasi teknis, estimasi kebutuhan per m² (jika bisa dihitung), informasi pengiriman, dan produk terkait.

## 4. Konten Teknis untuk Keperluan Riset
Selain deskripsi jualan, sertakan data teknis singkat (mutu beton, toleransi ukuran, berat per keping) — ini membantu pembeli yang masih riset (informational intent) sekaligus membangun trust untuk pembeli B2B yang mampir ke halaman produk sebelum request quotation.
