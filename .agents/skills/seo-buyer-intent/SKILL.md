# SEO Buyer Intent Cheatsheet (B2B — Kontraktor, Arsitek, Developer, Distributor)

Target pembaca: profesional B2B yang mencari supplier untuk kebutuhan proyek — bukan pembeli akhir rumah pribadi.

## 1. Kata Kunci B2B Intent
`supplier roster beton`, `pabrik roster beton`, `distributor roster beton`, `roster beton untuk kontraktor`, `roster beton untuk developer`, `roster custom motif arsitek`.

## 2. Halaman Dedicated per Segmen
Sesuai Master Plan, sediakan halaman terpisah (bukan hanya section di beranda):
`/untuk-kontraktor`, `/untuk-developer`, `/untuk-arsitek`, `/untuk-distributor`, `/supplier-roster-beton`.

Isi tiap halaman:
*   **Kontraktor & Pemborong**: pricelist grosir tangan pertama, kapasitas produksi, dokumen surat jalan & faktur resmi.
*   **Arsitek & Desainer**: konsultasi motif custom, sampel fisik untuk presentasi klien, akurasi presisi siku 90°.
*   **Developer Perumahan**: suplai bertahap skala klaster, jadwal presisi, armada pabrik sendiri.
*   **Distributor**: skema kerja sama reseller/distribusi, minimum order, wilayah distribusi.

## 3. Fitur Request Quotation (bukan checkout biasa)
Setiap halaman B2B wajib punya form Request Quotation, field minimal:
nama, perusahaan, jabatan, WhatsApp, email, jenis proyek, lokasi proyek, produk/motif, jumlah kebutuhan, satuan, deadline kebutuhan, catatan, upload file (opsional).

Jenis proyek yang dipilih user: perumahan, cluster, hotel, villa, cafe, restoran, apartemen, mall, kantor, masjid, sekolah, rumah sakit, commercial building, lainnya.

## 4. Alur Quotation B2B
```
Pilih produk → Masukkan kebutuhan → Request quotation → Review internal
→ Hitung harga volume → Cek kapasitas produksi → Cek pengiriman
→ Quotation dikirim → Approval customer → Invoice → DP → Produksi
→ Quality control → Pengiriman
```
**Jangan** memaksa order volume besar masuk ke jalur checkout B2C biasa — dua jalur ini harus tetap terpisah (B2C: Product → Cart → Checkout → Payment | B2B: Product → Request Quotation → Negosiasi → Invoice → Payment).

## 5. Content Cluster: Buyer
Artikel panduan per segmen (informational untuk B2B, membangun trust sebelum RFQ):
*   "Panduan Kontraktor Membeli Roster Beton"
*   "Panduan Developer Memilih Roster untuk Klaster Perumahan"
*   "Panduan Distributor Membeli Roster Grosir"

## 6. Trust Signal Wajib
Profesional mementingkan kepastian, bukan estetika semata:dokumen surat jalan & faktur resmi otomatis, bukti kapasitas produksi (jumlah keping/bulan), testimoni dari kontraktor/arsitek (bukan hanya homeowner) — **hanya testimoni yang benar-benar ada**, jangan dikarang.

## 7. Format Konten
Profesional mencari lebih cepat & spesifik — hindari gaya artikel inspirasi rumah untuk segmen ini. Gunakan tabel spesifikasi, PDF pricelist yang bisa diunduh, dan FAQ teknis (toleransi ukuran, waktu produksi custom, minimum order).
