# Keyword Research Cheatsheet

## 1. Lima Kategori Search Intent (jangan hanya kejar "roster + kota")

**Product Intent**: `roster beton`, `roster beton minimalis`, `roster beton modern`, `roster dekoratif`, `roster ventilasi`, `roster beton untuk fasad`, `harga roster beton`, `jual roster beton`.

**Location Intent**: `roster beton Bandung`, `roster beton Bekasi`, `roster beton Bogor`, `roster beton Jakarta`, `roster beton Cianjur`, `roster beton Cirebon`, `roster beton Sukabumi` — prioritas Jabodetabek & Jawa Barat dulu sebelum meluas ke kota lain di Indonesia.

**B2B Intent**: `supplier roster beton`, `pabrik roster beton`, `distributor roster beton`, `grosir roster beton`, `roster beton untuk kontraktor`, `roster beton untuk developer`, `roster beton partai besar`.

**Project/Kawasan Intent**: `roster beton untuk perumahan`, `roster beton untuk hotel`, `roster beton untuk cafe`, `roster beton untuk restoran`, `roster beton untuk fasad`, `roster beton untuk pagar`, `roster beton untuk proyek`.

**Informational Intent**: `cara menghitung kebutuhan roster`, `berapa roster per m2`, `ukuran roster beton`, `berat roster beton`, `harga roster beton`, `cara memasang roster beton`, `roster beton untuk ventilasi`.

## 2. Sinonim Penting di Indonesia
*   `Roster` (istilah modern/arsitektur)
*   `Loster` (istilah umum/lokal Jawa)
*   `Lubang angin` / `Ventilasi beton` (istilah umum perumahan)
*   `Kisi-kisi beton` (istilah teknik sipil)

## 3. Prioritas Riset Lokasi
Riset kata kunci lokasi diprioritaskan berdasarkan data nyata (search demand, aktivitas konstruksi, potensi pengiriman) — bukan otomatis semua kota. Gunakan Google Search Console untuk menemukan query lokasi yang sudah ada impresi tapi belum ada halaman khususnya (sinyal ekspansi lokasi baru).
