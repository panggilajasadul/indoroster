# Search Intent Alignment Cheatsheet

## 1. Memahami Maksud Pencarian (Intent)
*   **Informational (Belajar/Mencari Tahu)**: User ingin tahu kegunaan roster. Solusi: Buat halaman Galeri/Inspirasi proyek.
*   **Commercial Investigation (Banding Harga)**: User mencari produsen terbaik. Solusi: Tampilkan keunggulan K-200 pabrik kita dibanding kompetitor.
*   **Transactional (Siap Beli)**: User ingin memesan sekarang. Solusi: Tombol checkout langsung/pesan WA instan yang mencolok.
