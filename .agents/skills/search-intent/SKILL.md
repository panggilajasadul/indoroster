# Search Intent Alignment Cheatsheet

## 1. Lima Kategori Intent yang Harus Ditangani Berbeda
*   **Product Intent** — user mencari jenis/motif produk. Solusi: halaman katalog & detail produk yang lengkap datanya.
*   **Location Intent** — user mencari berdasarkan kota. Solusi: halaman kota dengan konten unik (lihat skill `local-seo`).
*   **B2B Intent** — user adalah kontraktor/arsitek/developer/distributor mencari supplier. Solusi: halaman dedicated per segmen + form Request Quotation.
*   **Project/Kawasan Intent** — user mencari berdasarkan jenis bangunan (hotel, cafe, perumahan) atau nama kawasan spesifik. Solusi: halaman/artikel use-case dan studi kasus proyek nyata.
*   **Informational Intent** — user belum siap beli, masih riset (cara pasang, ukuran, cara hitung kebutuhan). Solusi: artikel edukasi + kalkulator kebutuhan.

## 2. Tahap Funnel Klasik (tetap berlaku dalam tiap kategori di atas)
*   **Informational (Belajar/Mencari Tahu)**: User ingin tahu kegunaan roster. Solusi: halaman Galeri/Inspirasi proyek atau artikel edukasi.
*   **Commercial Investigation (Banding Harga/Supplier)**: User mencari produsen terbaik. Solusi: tampilkan keunggulan (mutu K-200, harga tangan pertama) dibanding kompetitor secara eksplisit.
*   **Transactional (Siap Beli/Siap Order)**: User ingin memesan sekarang. Solusi: tombol checkout langsung (B2C) atau Request Quotation (B2B) yang mencolok, sesuai skala kebutuhannya.

## 3. Jangan Salah Menempatkan CTA
Jangan tampilkan CTA "checkout instan" di halaman yang jelas-jelas menyasar B2B/volume besar (misal halaman "untuk kontraktor") — arahkan ke Request Quotation. Sebaliknya, jangan paksa pembeli individu mengisi form quotation panjang untuk pembelian eceran kecil.
